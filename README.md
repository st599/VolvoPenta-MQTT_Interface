# VolvoPenta-N2K_Interface
Interface to send the VP-CANbus-J1939 data to yout N2K network.
see: https://github.com/buhhe/VolvoPenta-N2K_Interface/blob/main/20211215%20J1939-N2K.pdf


# Connection in cable

double wire connector 

1 single brown
2 double blue CAN low
3 single white
4 double black Minus
5 double yellow CAN high
6 double red Plus

single connector 

1 blue CAN low
2 nc
3 yellow CAN high
4 black Minis
5 nc
6 red Plus
